CSV Format Instructions

Your CSV file should have the following columns:

  • full_name (required) - Member's full name
  • email (required) - Member's email address (must be unique)
  • phone_number (optional) - Phone number
  • gender (optional) - M, F, or Other
  • date_of_birth (optional) - Format YYYY-MM-DD
  • membership_type (optional) - daily, monthly, quarterly, annual (default: monthly)
  • membership_start_date (required) - Format YYYY-MM-DD
  • membership_expiry_date (required) - Format YYYY-MM-DD
    💡 Tip: Calculate based on membership type and start date:
    Daily = start_date + 1 day | Monthly = start_date + 30 days |
    Quarterly = start_date + 90 days | Annual = start_date + 365 days

Note: When creating members individually, dates auto-fill based on membership type!
